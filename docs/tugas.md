# File Tugas — Self-Service Analytics

## Brief tugas

Membuat, menjelaskan, dan mengimplementasikan **self-service analytics** menggunakan tools analytics (Power BI / Tableau / Looker Studio / Metabase). Dataset boleh dari repository publik. Hasil dipublish ke GitHub beserta `README.md` dan penjelasan penggunaan dalam kerangka self-service analytics.

## Implementasi yang dikerjakan

- **Tool dipilih:** Metabase (Docker)
- **Database:** MySQL (shared DB `webappskuliah`, tabel berprefix `metabase_`)
- **Dataset:** Telco Customer Churn (publik)
- **Deliverable:** repo ini (struktur folder + README + SQL + script import + dokumentasi)
